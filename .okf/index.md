# SmartLedger documentation metadata

This bundle holds the metadata of the human documents in this repository. The `resource` field of each concept points to its document. Edit the human document, then run `python3 scripts/docs/okf_sync.py` to update this bundle.

* [Contributing](CONTRIBUTING.md) - Commit, branch, pull request and merge rules, plus the PROGRESS.md format.
* [docs](docs/index.md) - Index of `docs`.
* [Mobile integration and native operations](frontend/mobile/docs/operations.md) - Detailed Mobile setup, provider configuration, speech packaging, report limitations and diagnostics.
* [Security policy](SECURITY.md) - How to report a vulnerability and what happens next.
