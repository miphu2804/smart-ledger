# Credential map

Environment-specific credential inventories and connection maps belong to the [private operations knowledge base](https://app.notion.com/p/M-i-tr-ng-v-domain-407f1ce5c3ac80249cd0c2a28c259436). Generated staging/production snapshots are not published in this repository.

Code declarations and `.env.example` files document the settings a developer needs, not the live credential assignment. Do not regenerate or commit environment snapshots as part of a repository change; use the authorized private maintenance process instead. No live credential values or private-knowledge-base contents were inspected by this documentation cleanup.
